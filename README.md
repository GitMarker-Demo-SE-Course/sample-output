# Sample output

This is the output of GitMarker for one team repository, [library-app-team-01](https://github.com/GitMarker-Demo-SE-Course/library-app-team-01). The course, the team members and all activity are made up for this demo.

GitMarker checked the activity from Tue 20 Oct 2026, 12:26 to Wed 21 Oct 2026, 21:15 (UTC), with the settings in [gitmarker-config.yml](gitmarker-config.yml).

| File | What it is |
|---|---|
| [output/reports/library-app-team-01.md](output/reports/library-app-team-01.md) | The report for the team. It can be shared with the students. |
| [output/summary.csv](output/summary.csv) | One row per repository: activity counts and how many times each check found a problem. |
| [output/violations.csv](output/violations.csv) | One row for each problem found, with the GitHub user, the time and a link. |
| [output/gitmarker-marks.xlsx](output/gitmarker-marks.xlsx) | The marking spreadsheet. Download it to open it. Change the yellow cells in Rubric Settings and the marks update. |
| [gitmarker-config.yml](gitmarker-config.yml) | The settings: which repositories, the time window, and the marking rules. |
| [roster.csv](roster.csv) | Links each GitHub username to a student ID and a team. |
